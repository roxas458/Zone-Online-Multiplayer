# ZONE ONLINE 4.33.35 — оптимизация, маршруты NPC и синхронизация

## Изменения
- Клиент Socket.IO теперь сначала пробует WebSocket, сохраняя polling как резервный транспорт. Это убирает обязательный polling-handshake на сетях, где WebSocket доступен.
- Синхронизация NPC на клиенте переведена на индекс по ID и группировку по локациям, чтобы не выполнять повторный линейный поиск каждого NPC внутри полного списка.
- В сетевом состоянии NPC теперь передаются `route`, `destinationPoint` и `destination`, необходимые для отображения маршрута.
- Карточка NPC на карте показывает позывной, группировку, роль, сектор, координаты, маршрут и пункт назначения; из карточки можно начать разговор.
- В карточке отряда каждый NPC выбирается отдельно.
- Маркер отряда теперь ставится в координаты ведущего NPC, на которого рассчитаны нажатие и радиус взаимодействия. Это устраняет расхождение между маркером и открываемой целью.
- При обновлении сетевых координат удаляются устаревшие локальные координаты, чтобы клиент не продолжал показывать NPC в старом месте.

## Проверки
- `node --check server.js` и `node --check public/js/game.js` — успешно.
- `npm run check` — успешно.
- `npm test` — 177 тестов пройдены, 0 ошибок.

## Примечание по серверу
Для обновления мультиплеера необходимо развернуть эту версию на том же сервере Render, к которому подключаются игроки. Изменение клиентского архива само по себе не обновляет уже работающий удалённый сервер.
